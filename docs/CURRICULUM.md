# Curriculum-Gerüst A1–B2

Arbeitsgrundlage für Phase 2 ff. Ergänzt `SPEC.md` Abschnitt 8. Reihenfolge und Themenwahl sind
an der Gliederung gängiger Grammatiken und Bildwörterbücher orientiert (siehe
`docs/REFERENCES.md`); Inhalte werden vollständig selbst geschrieben. Jede Unit nennt die
Engine-Funktionen, die sie voraussetzt (vgl. `docs/ENGINE_GAPS.md`).

Aufbau jeder Unit (SPEC 3.1): Erklärkarte → Wortschatz → Grammatik → ab A2 Dialog/Lesetext → Wiederholung.
