# Post und Telefon: Passiv und Reflexiv

## Das Passiv: -il, -in, -n

Das Passiv steht direkt am Verbstamm, **vor** Verneinung, Zeit und Person.

| Stamm endet auf | Passiv          | Beispiel                          |
| --------------- | --------------- | --------------------------------- |
| Konsonant       | -il/-ıl/-ul/-ül | yaz → yaz**ıl**dı, gönder**il**di |
| **l**           | -in/-ın/-un/-ün | çal → çal**ın**dı, bil**in**ir    |
| Vokal           | -n              | öde → öde**n**di, oku**n**du      |

- et → **ed**: teslim edilecek, davet edildim, iptal edildi.
- Der Aorist ist im Passiv immer -ır/-ir/-ur/-ür: yazılır, gönderilir, yenir.
- Verneint: yazıl**ma**dı, içil**mez**.
- Mit können: öde**n**ebilir mi? (kann man bezahlen?), kullanılabilir.

| Aktiv                        | Passiv                     |
| ---------------------------- | -------------------------- |
| Ali mektub**u** gönderdi.    | Mektup gönderildi.         |
| Ali hat den Brief geschickt. | Der Brief wurde geschickt. |

Das Objekt wird zum Subjekt und verliert den Akkusativ. Wer es getan hat, steht selten dabei, sonst mit **tarafından**: Mektup Ali tarafından yazıldı.

## „man“: Passiv im Aorist

Was „man“ tut, sagt man mit dem Passiv im Aorist:

| Türkisch                      | Deutsch                        |
| ----------------------------- | ------------------------------ |
| Bu kelime nasıl yazılır?      | Wie schreibt man dieses Wort?  |
| Türkçede bu nasıl söylenir?   | Wie sagt man das auf Türkisch? |
| Burada sigara içilmez.        | Hier wird nicht geraucht.      |
| Buradan müzeye nasıl gidilir? | Wie kommt man zum Museum?      |
| Postane saat dokuzda açılır.  | Die Post öffnet um neun.       |
| Kartla ödenebilir mi?         | Kann man mit Karte zahlen?     |

Auch Verben ohne Objekt haben dieses Passiv: gitmek → gidilir, konuşmak → konuşulur.

## selbst: kendi

| Person  | kendi    | Dativ     | Akkusativ |
| ------- | -------- | --------- | --------- |
| ich     | kendim   | kendime   | kendimi   |
| du      | kendin   | kendine   | kendini   |
| er/sie  | kendisi  | kendisine | kendisini |
| wir     | kendimiz | kendimize | kendimizi |
| ihr/Sie | kendiniz | kendinize | kendinizi |

- Bunu **kendim** yaptım. – Das habe ich selbst gemacht.
- **Kendine** iyi bak! / **Kendinize** iyi bakın! – Pass auf dich auf! / Passen Sie auf sich auf!
- **Kendimi** iyi hissetmiyorum. – Ich fühle mich nicht gut.
- **kendi** + Nomen mit Possessiv = eigen: kendi evimiz (unser eigenes Haus).
- kendi kendine – von selbst, allein.
- Für die 3. Person sagt man oft auch kendini statt kendisini.

## sich waschen: Reflexiv mit -in, -n

Manche Verben haben eine eigene reflexive Form mit -(i)n. Man lernt sie als Wörter:

| Mit Objekt               | Reflexiv                             |
| ------------------------ | ------------------------------------ |
| yıkamak (waschen)        | yıkanmak (sich waschen)              |
| giymek (anziehen)        | giyinmek (sich anziehen)             |
| hazırlamak (vorbereiten) | hazırlanmak (sich fertig machen)     |
| sevmek (lieben)          | sevinmek (sich freuen, eigenes Wort) |

Reflexiv ist immer -(i)n (giy-in, yıka-n), das Passiv nur nach Vokal -n (und -in nach l). Nach Vokal sehen beide gleich aus: Ali yıkandı. kann „Ali hat sich gewaschen“ oder „Ali wurde gewaschen“ heißen. Meist zeigt es der Zusammenhang.

## Auf der Post

- Bu paketi Almanya'ya göndermek istiyorum. – Ich möchte dieses Paket nach Deutschland schicken.
- Lütfen bu formu doldurun. – Füllen Sie bitte dieses Formular aus.
- Kimliğiniz, lütfen. – Ihren Ausweis, bitte.
- Paket üç gün içinde teslim edilir. – Das Paket wird innerhalb von drei Tagen zugestellt.
