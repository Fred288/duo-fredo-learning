# Wetter und Menschen: vergleichen

## Komparativ: -den daha

Das Vergleichsobjekt steht im **Ablativ** (-den/-dan/-ten/-tan), vor dem Adjektiv steht **daha** (mehr). Das Adjektiv selbst ändert sich nicht.

| Türkisch                       | Deutsch                            |
| ------------------------------ | ---------------------------------- |
| Ali Ayşe'**den** daha uzun.    | Ali ist größer als Ayşe.           |
| Bugün dün**den** daha soğuk.   | Heute ist es kälter als gestern.   |
| Tren otobüs**ten** daha hızlı. | Der Zug ist schneller als der Bus. |
| Kardeşim ben**den** küçük.     | Mein Bruder ist jünger als ich.    |
| Daha büyük bir oda istiyorum.  | Ich möchte ein größeres Zimmer.    |

- Mit Ablativ darf **daha** wegfallen: Ali Ayşe'den uzun.
- Ohne Vergleichsobjekt steht nur **daha**: daha ucuz (billiger), daha iyi (besser).
- **daha az** = weniger, **daha çok / daha fazla** = mehr.
- Bei Menschen: **uzun** (groß), **büyük / küçük** (älter / jünger), üç yaş küçük = drei Jahre jünger.

## Superlativ: en

**en** vor dem Adjektiv: en büyük, en ucuz, en iyi.

| Türkisch                             | Deutsch                         |
| ------------------------------------ | ------------------------------- |
| Türkiye'nin en büyük şehri İstanbul. | Die größte Stadt der Türkei …   |
| Ayşe en iyi arkadaşım.               | Ayşe ist meine beste Freundin.  |
| Ailenin en küçüğü benim.             | Ich bin der Jüngste der Familie |
| En ucuzu hangisi?                    | Welches ist das billigste?      |
| En çok çay içerim.                   | Am meisten trinke ich Tee.      |

Die größte Stadt **der Türkei** ist eine Genitiv-Possessiv-Verbindung: Türkiye'**nin** … şehr**i** (wie Ali'nin evi). Steht das Adjektiv allein, bekommt es selbst das Possessiv: en küçüğü (der Jüngste davon), en ucuzu (das Billigste davon).

## so … wie: kadar

| Türkisch                           | Deutsch                         |
| ---------------------------------- | ------------------------------- |
| Ali Mehmet **kadar** uzun.         | Ali ist so groß wie Mehmet.     |
| Bugün dün kadar sıcak değil.       | Heute ist es nicht so heiß.     |
| Ben sen**in** kadar hızlı değilim. | Ich bin nicht so schnell wie du |

Nomen bleiben vor kadar in der Grundform, **Pronomen** stehen im Genitiv: benim kadar, senin kadar, onun kadar, bizim kadar.

## Wie sehr?

| Wort    | Bedeutung                        | Beispiel       |
| ------- | -------------------------------- | -------------- |
| çok     | sehr                             | çok soğuk      |
| oldukça | ziemlich                         | oldukça soğuk  |
| biraz   | etwas, ein bisschen              | biraz yorgunum |
| pek     | besonders (meist mit Verneinung) | pek iyi değil  |
| hiç     | überhaupt (nicht)                | hiç benzemiyor |

**Verstärkung durch Vorsilbe:** der Wortanfang bis zum ersten Vokal plus m, p, r oder s. Welcher Konsonant kommt, lernt man mit dem Wort.

| einfach | verstärkt  |
| ------- | ---------- |
| beyaz   | bembeyaz   |
| yeşil   | yemyeşil   |
| mavi    | masmavi    |
| kara    | kapkara    |
| sarı    | sapsarı    |
| kırmızı | kıpkırmızı |
| temiz   | tertemiz   |

## Menschen beschreiben

- **nasıl biri?** – was für ein Mensch? Kardeşin nasıl biri?
- uzun boylu / kısa boylu (groß / klein gewachsen), zayıf (schlank), şişman (dick)
- Saçları uzun ve siyah. – Sie hat lange schwarze Haare.
- mavi gözlü (blauäugig), sarı saçlı (blond): -lı/-li = mit, mehr in A2-09.
- genç (jung), **yaşlı** (alt, Mensch), **eski** (alt, Ding)
- Annene **benziyorsun** (benzemek + Dativ). Yorgun **görünüyorsun** (du siehst müde aus).

Erweichende Wörter erweichen auch vor -im/-iz des Nominalsatzes: genç → **genc**im, büyük → **büyüğ**üm; vor Konsonant nicht: gençsin, küçüktüm.
