# Arbeit und Einkauf: Ableitungen und -ki

Mit wenigen Suffixen entstehen aus einem Wort neue Wörter. Sie stehen direkt am Stamm, **vor** Plural, Possessiv und Kasus: kitap-çı-lar-ımız-a.

## -ci: wer damit arbeitet

| Stamm  | + -ci       | Bedeutung              |
| ------ | ----------- | ---------------------- |
| gazete | gazeteci    | Journalist(in)         |
| yol    | yolcu       | Reisende(r), Fahrgast  |
| süt    | sütçü       | Milchmann              |
| kitap  | kitap**ç**ı | Buchhändler, Buchladen |
| balık  | balık**ç**ı | Fischer, Fischhändler  |
| iş     | iş**ç**i    | Arbeiter(in)           |

- Vierfache Harmonie: -ci, -cı, -cu, -cü.
- Nach einem **stimmlosen** Laut (p, ç, t, k, s, ş, f, h) wird c zu **ç**, wie d zu t: kitapçı, çiçekçi, simitçi.
- Oft heißt das Wort auch der Laden: kitapçıya gidiyorum (in die Buchhandlung).

## -li und -siz: mit und ohne

| Stamm          | -li (mit) | -siz (ohne) |
| -------------- | --------- | ----------- |
| şeker          | şekerli   | şekersiz    |
| süt            | sütlü     | sütsüz      |
| çocuk          | çocuklu   | çocuksuz    |
| iş             | –         | işsiz       |
| ücret (Gebühr) | –         | ücretsiz    |

- **Herkunft:** Ankaralı, İstanbullu, Berlinli, nereli? – ohne Apostroph, weil ein neues Wort entsteht. Aber Berlin'de, Berlin'deki.
- **Eigenschaften:** evli (verheiratet), bahçeli ev (Haus mit Garten), balkonlu daire, mavi gözlü, renkli (bunt), indirimli (reduziert).
- Wörter, die erweichen, erweichen davor nicht: renk → renkli, kitap → kitapsız.

## -lik: Dinge und Begriffe

| Stamm   | + -lik      | Bedeutung         |
| ------- | ----------- | ----------------- |
| göz     | gözlük      | Brille            |
| tuz     | tuzluk      | Salzstreuer       |
| kitap   | kitaplık    | Bücherregal       |
| güzel   | güzellik    | Schönheit         |
| arkadaş | arkadaşlık  | Freundschaft      |
| çocuk   | çocukluk    | Kindheit          |
| sağ     | sağlık      | Gesundheit        |
| hafta   | haftalık    | wöchentlich       |
| kişi    | iki kişilik | für zwei Personen |

- -lik erweicht vor Vokal: gözlü**ğ**üm (meine Brille), sağlı**ğ**ı.
- Ableitungen lassen sich stapeln: temiz → temizlik (Sauberkeit) → temizlikçi (Reinigungskraft), kitapçılık (Buchhandel).

## -ki: der/die/das in …, von …

**Lokativ + ki** macht aus einer Ortsangabe ein Adjektiv:

| Türkisch                    | Deutsch                    |
| --------------------------- | -------------------------- |
| masa**daki** kitap          | das Buch auf dem Tisch     |
| İstanbul'**daki** arkadaşım | mein Freund in Istanbul    |
| vitrin**deki** ayakkabılar  | die Schuhe im Schaufenster |

**Zeitwort + ki:** yarın**ki** toplantı (die morgige Besprechung), akşam**ki**, şimdi**ki**. Nur drei Wörter haben **kü**: bugün**kü**, dün**kü**, öbür**kü**.

**Genitiv + ki** ersetzt ein Nomen (meins, deins):

| benimki | seninki | onunki      | Ali'ninki           |
| ------- | ------- | ----------- | ------------------- |
| meins   | deins   | seins, ihrs | der/die/das von Ali |

- Benim çantam siyah, **seninki** kırmızı.
- Danach können Plural und Kasus folgen: evdeki**ler** (die Leute im Haus), evdeki**ni** (mit n vor dem Akkusativ).
- -ki harmonisiert sonst nicht (Ausnahmen oben): masadaki, okuldaki.

## Einkaufen

- Bu ne kadar? / Fiyatı ne kadar? – Wie viel kostet das?
- Bunun bir büyük bedeni var mı? – Gibt es das eine Nummer größer?
- Nakit mi, kartla mı? – Bar oder mit Karte?
- Kredi kartıyla ödeyebilir miyim? – Kann ich mit Kreditkarte zahlen?
- Poşet ister misiniz? – Möchten Sie eine Tüte?
