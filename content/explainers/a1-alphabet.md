# Das türkische Alphabet

Türkisch wird lateinisch geschrieben und fast immer so ausgesprochen, wie es geschrieben wird.
29 Buchstaben, kein q, w, x. Neu für Deutschsprachige:

| Buchstabe | Aussprache                           | Beispiel      |
| --------- | ------------------------------------ | ------------- |
| c         | wie „dsch“ in Dschungel              | cam (Glas)    |
| ç         | wie „tsch“                           | çay (Tee)     |
| ğ         | dehnt den vorigen Vokal, kaum hörbar | dağ (Berg)    |
| ı         | dumpfes i, ohne Punkt                | kız (Mädchen) |
| İ / i     | normales i; auch groß mit Punkt      | İstanbul      |
| ş         | wie „sch“                            | şehir (Stadt) |
| z         | stimmhaftes s wie in „Sonne“         | göz (Auge)    |
| v         | wie deutsches w                      | ev (Haus)     |

Achtung bei Groß/Klein: `I` gehört zu `ı`, `İ` gehört zu `i`.
